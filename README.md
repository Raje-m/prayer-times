# 🌙 تطبيق مواقيت الصلاة والورد اليومي (Islamic Prayer & Athkar App)

تطبيق ويب متطور وحديث لإدارة مواقيت الصلاة، الأذكار، القبلة، والمسبحة الرقمية، مصمم بأعلى معايير الأداء والسرعة باستخدام أحدث تقنيات الويب.

---

## ✨ المميزات والخصائص الرئيسية

- 🕋 **مواقيت الصلاة الدقيقة:** جلب المواقيت بناءً على المدن أو عبر تحديد الموقع الحالي (GPS).
- 🌙 **الوضع الليلي الحقيقي (OLED Deep Dark Theme):** تصميم مخصص للشاشات الحديثة لتوفير البطارية ومنح راحة تامة للعينين.
- ⚡ **أداء فائق السرعة:** تطبيق تقنيات الـ `Code Splitting` و `React.memo` لمنع إعادة التصيير الزائد.
- 💾 **التخزين المؤقت (Caching):** حفظ البيانات محلياً عبر `LocalStorage` لضمان عمل التطبيق بسلاسة تامة وحتى بدون إنترنت.
- 🧭 **بوصلة القبلة والمسبحة الرقمية:** أدوات إضافية متكاملة لخدمة المسلم.
- 📱 **دعم PWA:** قابل للتثبيت كبرنامج حقيقي على الهواتف الذكية وأجهزة سطح المكتب.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **React.js (Vite):** لبناء واجهات مستخدم تفاعلية وعالية الأداء.
- **Redux Toolkit:** لإدارة الحالة العامة للتطبيق وتخزين مواقيت الصلاة.
- **Tailwind CSS:** للتصميم المرن والمتجاوب مع دعم متغيرات الألوان.
- **Axios:** للتعامل مع طلبات الـ API.
- **Aladhan API:** مصدر بيانات مواقيت الصلاة.
